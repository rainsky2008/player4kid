# 杜丫丫/姜子丫 宝贝视听（netdisk-player4kid）

杜丫丫/姜子丫播放器的互联网服务商关停服务了，硬件放着浪费，本项目结合baidu网盘，直接播放百度网盘的内容。

给不会编程的家长看的安装步骤见 [`新手使用说明.md`](新手使用说明.md)。

## 功能

| 功能 | 说明 |
| --- | --- |
| 接管桌面 | 注册为 HOME 桌面；设为默认桌面后，孩子按 Home 键只会回到本桌面。被切到后台（最近任务、通知栏）会自动拉回前台。孩子的页面全屏显示。可选“设备所有者”锁定模式，彻底屏蔽 Home、最近任务和通知栏 |
| 儿童首页 | 晴空背景；顶部“今天还能看 X 分钟”下面是分格的**时间能量条**（每格 5 分钟，快用完时由绿变黄再变红），孩子数格子就知道还能看多久；文件夹卡片像积木，封面在上、名字在下（自动去掉 01、02. 这类排序编号），听的文件夹标 🎧；**今天的视频时间用完后，视频文件夹变灰并显示“🌙 明天再看”，听的照常可以点** |
| 设置按钮 | 桌面右上角 ⚙ 按钮，输入家长密码后可打开 **系统设置**、**WLAN**、**家长设置** |
| 网盘资源 | 家长扫码登录百度网盘。资源目录（默认 `/apps/player4kid`）里的**每个文件夹都单独显示在桌面上**，以后新建的文件夹会自动出现；卡片封面优先用文件夹里的 `封面.jpg`（也认 cover / folder，jpg / png），没有就随机挑一个视频的画面（没有视频时随机到子文件夹里找，最多两层；封面存在本地，7 天换一次；放了或换了封面图后在家长设置里点“刷新目录”）；文件夹里的子目录、视频、音频都会列出（按数字大小排序：001 < 002 < 010，1 < 4 < 05 < 10，补零不补零都可以）。也可以另外添加其他目录 |
| 每日视频时长 | 默认 60 分钟，可配置；用完后当天不能再看视频，可以听音频 |
| 单次观看时长 | 默认连续看 20 分钟后**强制弹出休息界面**，休息 10 分钟；休息结束后可“继续看”，直到当日时长用完。最后 1 分钟会提示 |
| 音频 | 不限时；后台播放（前台服务），**无操作 15 秒自动息屏**，只听不看。点一个音频，同一目录里的音频按顺序（001、002…）自动加入播放列表，从点的那个开始播；播放列表可以删除（✕）、拖动调整顺序（≡）、收起 / 展开；播放页和首页底部的“正在听”条显示目录完整标题和文件名（首页太长时滚动显示），“正在听”条可以点 ✕ 关掉（停止播放） |
| 播放体验 | 记住每集看到哪里；自动连播下一集；转码失败自动改用原画 |
| 家长功能 | 临时加时、提前结束休息、清零今天、修改密码、播放清晰度 |

只统计视频**真正在播放**的时间（缓冲和暂停不计）。停下来不计时，但**也不算休息**：暂停、退出、关机、重启后再看，连续观看时间接着累计，只有看满时长被强制休息后才重新计算（家长可以在设置里“结束休息”或“清零今天”）。

首页、目录、播放页、休息页的时间提示用同一套规则（`core/TimeTexts.kt`），数字一致：能看的时间向下取整（剩 18 分 39 秒时，首页和目录说“18 分钟”，播放页显示“还能看 18:39”），要等的休息时间向上取整；并说清楚这次看完是“要休息 10 分钟”还是“今天的视频就看完了”。

所有计时都保存在平板上，**重启、覆盖安装、被系统杀掉都不会清零**（看视频时每 5 秒保存一次，强制休息等关键时刻立即保存）。只有卸载、清除应用数据，或到了第二天才会清零。

## 一、准备百度网盘开放平台应用

1. 打开 <https://pan.baidu.com/union>，登录后进入控制台并创建应用，记下 **AppKey** 和 **SecretKey**。
2. 本程序使用 **设备码模式（扫码）** 授权（scope = `basic,netdisk`），家长用手机扫描平板上的二维码即可登录。

> ⚠️ **两个平台限制（来自官方文档，请务必了解）**
>
> - **目录范围**：新创建的应用默认只能访问 `/apps/应用名`，在网盘 App 里显示为“我的应用数据 → 应用名”。请把给孩子看的视频、音频按文件夹放到这个目录下面（例如 `/apps/player4kid/小猪佩奇`），每个文件夹会自动成为桌面上的一张卡片。选择目录时如果根目录没有权限，程序会自动跳到 `/apps`，也可以点“输入路径”直接填写。
> - **调用次数**：未审核的应用接口调用次数很少，授权用户数也有限。程序为此做了这些节省：
>   - 目录列表缓存 6 小时，接口失败时使用旧缓存；
>   - 播放地址缓存 7 小时；
>   - 接口报错时不会自动重试。
>
>   如果经常提示“超出接口次数限制”，请在开放平台申请应用审核或提高配额。

## 二、编译

需要 JDK 17 和 Android SDK（compileSdk 35）。

1. （可选）把 [`local.properties.example`](local.properties.example) 复制一份，改名为 `local.properties`，填上百度网盘开放平台的 `baidu.appKey` / `baidu.secretKey`。填了以后安装包自带 Key，装好后不用在平板上再输入；不填就在 App 的家长设置里填。

   `local.properties` 里有你自己的 Key，已经被 `.gitignore` 排除，不要提交到代码仓库。

2. 编译：

   ```bash
   ./gradlew assembleDebug
   # 生成：app/build/outputs/apk/debug/app-debug.apk
   ```

发给别人用的安装包请编译**公开版**，不会把 `local.properties` 里你自己的 AppKey / SecretKey 编进去（对方装好后在家长设置里填他自己的）：

```bash
./gradlew assembleRelease -PpublicBuild=true
# 生成：app/build/outputs/apk/release/app-release.apk
```

运行单元测试：`./gradlew testReleaseUnitTest`

## 三、安装和首次设置

```bash
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

1. 按平板的 Home 键，选择“宝贝视听”，再选“始终”，把它设为默认桌面。
2. 点右上角 ⚙，第一次使用需要先设置**家长密码**（4~8 位数字）。
3. 进入“家长设置”，按顺序完成：
   1. 填写 AppKey / SecretKey，点“扫码登录”，用手机百度网盘 App 扫码授权；
   2. 确认“资源目录”是 `/apps/player4kid`（默认就是），里面的每个文件夹会自动显示在桌面上；需要的话也可以“添加其他目录”；
   3. 设置每日时长、单次时长和休息时长；
   4. 点“激活设备管理器”，听音频时才能真正息屏。不激活时只会黑屏并调到最低亮度。

## 四、（推荐）强力锁定：设备所有者模式

普通模式下，孩子仍可能从下拉通知栏操作一些快捷开关。设为**设备所有者**后，程序会进入系统的“锁定任务模式”：

- Home、最近任务、通知栏全部失效；
- 禁止修改系统时间，防止改时间刷时长；
- 自动成为默认桌面。

前提：设备上**不能登录任何账号**（设置 → 账号 里全部移除），并且已经安装本程序。

```bash
adb shell dpm set-device-owner com.netdisk.player4kid/.core.AdminReceiver
```

家长打开“系统设置 / WLAN / 原来的桌面”时，程序会临时退出锁定模式，回到本桌面后自动恢复。

**卸载前**：在“家长设置 → 桌面与防护”中点“解除设备所有者”，然后才能正常卸载。

## 五、常见问题

- **忘记家长密码**：`adb shell pm clear com.netdisk.player4kid` 会清除本应用的全部数据，需要重新设置。
- **网盘里新加了文件看不到**：在家长设置里点“刷新目录”，或者在孩子界面长按目录标题。
- **视频开始前要等十几秒**：普通用户使用转码播放时，网盘要求先等待“广告时间”，会员没有这一步。也可以在家长设置里改为“原画”，但非会员原画下载可能限速。
- **听音频不息屏**：需要先激活设备管理器（家长设置 → 桌面与防护）。

## 代码结构

```text
app/src/main/java/com/netdisk/player4kid/
├── App.kt                  # 全局单例、OkHttp、前后台统计（防退出）
├── baidu/
│   ├── BaiduApi.kt         # 设备码登录、刷新令牌、列目录（带磁盘缓存）、filemetas/dlink、转码 m3u8（含 errno 133 广告等待）
│   └── PanFile.kt          # 文件模型、视频/音频识别、自然排序
├── web/
│   └── WebLibrary.kt       # 自建视频服务器（可选）
├── core/
│   ├── PlayTimeManager.kt  # 每日时长 / 单次时长 / 休息状态（持久化）
│   ├── TimeTexts.kt        # 孩子看到的时间提示（首页 / 目录 / 播放页 / 休息页共用）
│   ├── FolderCovers.kt     # 桌面卡片封面：封面.jpg 优先，否则随机一个视频的缩略图，下载到本地缓存
│   ├── KidNames.kt         # 首页卡片上的文件夹名（去掉排序编号）
│   ├── Prefs.kt            # 家长设置、令牌、播放进度
│   ├── Kiosk.kt            # 默认桌面、锁定任务、拉回前台、息屏（lockNow）
│   └── AdminReceiver.kt    # 设备管理器 / 设备所有者
├── player/
│   ├── PanMedia.kt         # 网盘文件 → MediaItem（bdpan://dlink、bdpan://stream）
│   ├── PanDataSource.kt    # 播放时解析真实地址、设置 UA、返回 m3u8
│   ├── AudioEngine.kt      # 全局音频播放器（不计时）；播放列表的生成、删除、调整顺序
│   ├── AudioService.kt     # MediaSessionService，息屏后台播放
│   └── VideoQueue.kt       # 当前视频播放列表（休息后“继续看”）
└── ui/
    ├── BaseKidActivity.kt  # 孩子页面的基类：全屏、锁定任务、听音频时自动息屏
    ├── LauncherActivity.kt # 桌面首页（HOME）
    ├── TimeBar.kt          # 首页的时间能量条
    ├── BrowseActivity.kt   # 浏览目录
    ├── VideoPlayerActivity.kt  # 视频播放 + 计时 + 强制休息
    ├── AudioPlayerActivity.kt  # 音频播放 + 自动息屏 + 可编辑的播放列表（横屏左右分栏）
    ├── RestActivity.kt     # 强制休息倒计时
    ├── FullscreenDialogs.kt    # 在全屏页面上弹对话框时不让状态栏闪出来
    └── parent/             # 家长密码、家长设置、扫码登录、目录选择
```
